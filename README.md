# IMDB Data Normalization

This project cleans and normalizes a dirty IMDb dataset and produces a clean, structured CSV file ready for analysis.

The main goal is to standardize inconsistent values (dates, countries, genres, numbers, ratings, etc.) using Pandas and custom normalization logic.

## 📄 File Descriptions

### **transform.py**
- Entry point of the project
- Reads the raw IMDb dataset
- Applies all normalization and cleaning steps
- Outputs the cleaned CSV file

Run this file to execute the full pipeline.

---

### **utils.py**
- Contains all normalization functions
- Handles:
  - Duration normalization
  - Ratings normalization
  - Votes normalization
  - Income (USD) normalization
  - Title normalization
  - Content rating cleanup
- Used heavily by `transform.py`

---

### **regex_date_spanish.py**
- Handles inconsistent or malformed date formats
- Focuses on rewriting non-standard or localized (e.g. Spanish) date formats into a consistent format

---

### **countries.py**
- Stores country mappings and normalization logic
- Used to fix misspellings, abbreviations, and inconsistencies in the `Country` column
  - Example: `US`, `USA`, `US.` → `United States`
  - `New Zesland`, `New Zeland` → `New Zealand`

---

### **messy_IMDB_dataset.csv**
- Original raw dataset
- Contains inconsistent, malformed, and unnormalized data

---

### **cleaned_IMDB_dataset.csv**
- Final cleaned output
- Generated by running `transform.py`
- Fully normalized and ready for analysis

---

### **__pycache__/**
- Automatically generated Python cache files
- Can be safely ignored
